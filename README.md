Hi, Welcome to my email app! The purpose of this web app is for users to upload an email, and then my app will tell you if the email contains malicious content, any sort of phising attempt, and the risk level of the uploaded file. In order to run the app, launch a codespace, run the command "npm install", followed by "npm run dev". If that doesn't work in the terminal, try re-running both commands in the same order as before. Once the app is up in running in your codespace, a pop up will ask if you want to open in browser, click that and it will take you to the email app!
